DEEPTHORT DESKTOP v24 — large specifications and approval-backed test evidence

Preserves the original desktop interface, Windows launcher, offline Qwen, JANUS/Sentinel,
explicit approvals, state, model files, and 40-attempt planning batches.

The small 250,000-character storage limits are raised to 120,000,000 characters.
This does NOT enlarge the ONNX context window; enormous specifications are stored
intact and processed in hash-checked, resumable model sections. Incomplete section
coverage cannot produce an approved plan.

To import a large TXT/MD/JSON/YAML specification without pasting it into Tk:
right-click inside the Chats prompt editor -> Import large specification,
or press Ctrl+Shift+O. You can add extra requirements in the text editor.

Approved JANUS project checks are recorded as evidence (not proof of correct games).
Procedure promotion requires current artifacts plus approved successful test receipts.
See CAPABILITY_LIBRARY.md for the supported command and evidence scopes.

Install: EXIT DeepThorT first; extract this ZIP into D:\deepthort, retaining your
existing state/, models/, node_modules/, cache/, reference/ and project folders.
Back up state/ before importing enormous specifications. No game, APK or mod is
considered built merely because a plan or test receipt exists.
