Universal Gate Benchmark

This dashboard is generated from a reproducible batch analysis of the pinned WikiPron pronunciation corpora and PHOIBLE feature system. It asks whether the proposed sixteen-state bridge produces stable gate structure across languages, families and powers-of-three overlays.

Method control: the benchmark reports complete-corpus footprints and a deterministic equal-size sample for cross-language comparison. Powers-of-3 transition profile

A cell with magic value n carries 3^(n−1). A gate therefore has ratio 3^Δ where Δ = exponent(target) − exponent(source). The benchmark measures which Δ values recur across languages.

Interpretation: a useful universal bridge should show a non-trivial high-prevalence core, substantial pairwise support overlap, low unreachable rerouting mass, and broadly recurring powers-of-three exponent deltas.
