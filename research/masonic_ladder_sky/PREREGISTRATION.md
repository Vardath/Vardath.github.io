# Ladder / sky / lattice test

Preregistered 2026-09-13 before results are inspected.

Question: are Masonic ladder records more strongly embedded in a celestial and lattice-like symbolic context than matched non-Masonic ladder records?

Primary endpoint: presence of sky/heaven/star/sun/moon/celestial/firmament/zodiac/constellation/cloud/vault/canopy language.

Secondary endpoints:
- lattice structure excluding the word ladder: rail, rung, crossbar, parallel, grid, lattice, mesh, net, interlace, woven, crossing, transverse;
- celestial plus lattice structure;
- axis language: pillar, column, rod, staff, tree, tower, obelisk;
- celestial plus axis.

Corpus: 20 Wikimedia Commons shards. Each shard has one Masonic-ladder query and one neutral non-Masonic ladder query. Target records must contain a Masonic label; controls containing Masonic labels are excluded.

Matching: word-count bin plus nearest available date.

Primary prediction: celestial context will be enriched in the Masonic ladder set, with RR above 1.5 and BH-FDR q below 0.05.

Negative controls: portrait/bust, horse/equestrian, furniture, garment/costume, landscape.

A positive result supports a narrower ladder/sky symbolic association. A null result counts against that association. The query map, vocabularies and endpoints are frozen before the merge is inspected.
