# Masonic ladder / sky / lattice pilot — 20-shard result

GitHub Actions run: 34760337417

The preregistered pilot completed successfully across 20 Wikimedia Commons shards, but the acquisition design proved underpowered and contaminated by irrelevant ladder records.

- 708 unique records across target and control retrieval.
- Only 15 matched Masonic-ladder / non-Masonic-ladder pairs survived.
- Primary celestial context: 2/15 (13.33%) target vs 2/15 (13.33%) control; RR 1.00; Fisher p=1.0; BH q=1.0.
- Lattice-structure language: 7/15 (46.67%) target vs 4/15 (26.67%) control; RR 1.75; p=0.450; q=1.0.
- Axis language: 3/15 (20.0%) target vs 1/15 (6.67%) control; RR 3.00; p=0.598; q=1.0.
- Celestial + lattice structure: 0/15 target vs 2/15 control.

Inspection showed that retrieval conditioned directly on `masonic + ladder`, producing a very small usable sample and admitting irrelevant hook-and-ladder/road records. The pilot is therefore retained as a null/underpowered first attempt rather than treated as a decisive test of the hypothesis.

A corrected v2 validation was preregistered separately. V2 retrieves broad Masonic symbolic art without using `ladder` as a retrieval term, then independently classifies ladder/ascent, celestial, lattice-structure and axis language inside that corpus.
