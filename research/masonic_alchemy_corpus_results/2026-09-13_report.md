# Freemason + Alchemical Visual Grammar Test — Results

**Protocol:** preregistered before acquisition; 20 GitHub shards.

## Corpus

- **8,486 unique records** after cross-shard deduplication.
- **3,568 matched target records** and **3,568 matched controls** used in the primary analysis.
- Sources: Wikimedia Commons visual/file metadata and Open Library book/document metadata.
- Shards 0–9: Commons visual records, 100 target + 100 control candidates per shard after the acquisition cap.
- Shards 10–19: Open Library document records, usually 400 target + 400 control candidates per shard.

## Primary preregistered endpoint

Records with **3 or more** predicted Vardath symbol families:

- target: **4/3568 = 0.11%**
- control: **7/3568 = 0.20%**
- risk ratio: **0.57×**
- odds ratio: **0.60**
- Fisher p = **0.549**
- BH-FDR q = **1.0**

The broad package-density prediction therefore **did not reproduce**. Masonic/alchemical records were not generally more likely than matched controls to carry three or more of the eight declared Vardath families in their catalogue/document metadata.

The looser `>=2 families` test was also not enriched: **0.56% target vs 0.78% control, RR 0.71×**.

## Tradition-specific package density

- **Freemason/Masonic:** 0.06% target vs 0.23% control for >=3 families; RR 0.25×; q = 0.96.
- **Alchemy:** 0.16% target vs 0.16% control; RR 1.00×; q = 1.0.

## Predeclared pair tests

The explicit two-family combinations were sparse and none survived FDR correction. Examples:

- Masonic axis + gate/ladder: 0.17% vs 0%, q = 0.788.
- Masonic four/eight + node/radiance: 0.06% vs 0%, q = 1.0.
- Alchemical serpent/braid + axis: 0.11% vs 0%, q = 0.976.
- Alchemical water/vessel + enclosure: 0% vs 0%, q = 1.0.

Thus the successful part of the preregistered prediction is **family specialization**, not dense metadata-level co-occurrence of whole symbol packages.

## Source-channel robustness observations

These checks were performed after the preregistered aggregate was complete and are therefore **exploratory robustness checks**, not replacements for the primary analysis.

### Masonic four/eight geometry
- Wikimedia Commons: **4.46% target vs 0.84% control; RR 5.33×; Fisher p = 0.00395**.
- Open Library: **0.58% target vs 0%; Fisher p = 0.00773**.

The direction therefore repeated in both source channels.

### Masonic gate / ladder
- Wikimedia Commons: 4.46% vs 4.74%; RR 0.94×.
- Open Library: **1.96% vs 0.145%; RR 13.5×; p = 1.45e-06**.

The aggregate gate/ladder effect is document-channel driven.

### Alchemical serpent / braid
- Wikimedia Commons: **12.55% target vs 0%; Fisher p = 3.86e-11**.
- Open Library: 0.384% vs 0.192%; RR 2.0×; p = 0.507.

The serpent/braid result is primarily a **visual-art channel** result.

### Alchemical paired polarity
- Wikimedia Commons: 0.74% vs 1.85%; RR 0.40×.
- Open Library: **2.24% vs 0.064%; RR 35×; p = 8.98e-10**.

The paired-polarity aggregate is therefore document-channel driven.

## Post-hoc historical restriction

A known-year **<=1930** restriction was applied after the main result as a robustness check and re-matched using the same matching rule. It yielded 781 target-control pairs.

- Primary >=3-family package: 0.26% vs 0.13%, RR 2.0×, Fisher p = 1.0 — still not supported.
- Masonic four/eight: **2.21% vs 0.40%, RR 5.5×, p = 0.0216**.
- Masonic gate/ladder: **2.41% vs 0.40%, RR 6.0×, p = 0.0123**.
- Alchemical serpent/braid: **5.65% vs 0%, Fisher p = 2.45e-05**.
- Alchemical paired polarity: **0.35% vs 0.35%, RR 1.0×**.

Thus the three historically anchored effects—Masonic four/eight, Masonic gate/ladder, and alchemical serpent/braid—remain in the early/historical slice, while the full-corpus paired-polarity signal does not.

## Reproducibility boundary

This is a metadata/text-annotation corpus test. It measures whether predeclared symbolic families are explicitly represented in file descriptions, titles and book subject metadata. It is not yet a pixel-level blinded image test. The preregistration, 20-shard workflow and test code are stored in the repository so later image-level tests can be compared against this frozen baseline.
