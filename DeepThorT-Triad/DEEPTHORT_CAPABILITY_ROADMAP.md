# DeepThorT capability comparison and development roadmap
Review: 24 November 2026. Baseline source 2b4bdec (previous CI failed three GUI fixtures; corrected in this pass). This is a documented feature comparison, not a measured model benchmark. LLM means Simon Willison's LLM CLI as well as the underlying model layer. Current source is v61; do not conflate source with released Windows v60.

## Architecture that must remain
Local Qwen2.5-Coder-1.5B-Instruct ONNX; JANUS and Sentinel independent persistent coordinators; preserve exact original specification and amendments, current eight-tab desktop, saved projects, state, and verified source. Gaming-first shared 30% CPU and committed-memory cap; no cloud fallback, no arbitrary unreviewed execution, normal Windows UAC. Do not add Ollama, llama.cpp or additional LLMs as a shortcut. No project-specific hardcoded plans. Smaller model quality is not equivalent to larger hosted models, and agent orchestration cannot guarantee equivalence.
