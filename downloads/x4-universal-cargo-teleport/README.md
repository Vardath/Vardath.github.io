# Vardath — Universal Cargo Teleportation

**Native AI XML only; compatible by design with Protected UI Mode being ON.**

[Download the installable ZIP](./vardath_universal_cargo_teleport_TEST.zip)

Grants dockless cargo transfer capability to **all player-owned S/M/L/XL ships** carrying out existing AI trade or ware-exchange orders (within 30 km, same zone). No research, UI plugin or special ship equipment. Applies to existing saves; no new game.

Normal player-ship trading with stations (including NPC stations) uses normal X4 `execute_trade` accounting; ship-to-ship ware exchanges between two player-owned ships are handled without docking when both are in range. Ships approach when necessary; if a teleport cannot complete, native order handling remains available.

**Caution:** Source is XML checked and selectors were checked against public 8.00 reference AI scripts; actual X4 9.00 live testing has not been performed. Some trade/order mods may conflict. This does not give the manually piloted player ship a new UI button or perform unsolicited ware balancing.
