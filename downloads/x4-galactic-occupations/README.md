# Galactic Occupations 0.3.0 — station hacking and patrol payments

[Download Occupations](Galactic_Occupations_0.3.0_DEV.zip) · [Four-mod bundle](../x4-updates/X4_Hacker_Jobs_Update_2026-11-07.zip) · [Log and implementation report](vardath_galactic_occupations/HACKER_REVIEW_0.3.0.md) · [Full instructions](vardath_galactic_occupations/README.md)

Adds a thirteenth galaxy-wide behaviour, Galactic Station Hacker, and an additive native right-click station submenu for one selected panel. Uses an existing crew member/captain, actual tools remotely reserved from player inventory, native NPC room movement and the native panel action. Requires the real panel effect and the same NPC's return before completion. Missing tools retry every ten game minutes. No crew clones, ashore teleports, fabricated effects or hacker wages.

The supplied log confirms four successful trade patrol arrivals but zero income because that task previously specified 0 Cr. Verified foreign-trader arrivals now pay 8,000 Cr. Debug payment records include actual balance changes; General paid receipts and the original vanilla ledger remain in place. All-size crystal harvesting and direct player-inventory collection fixes from 0.2.5 are retained.

Fully exit X4, overwrite the matching extension folder, restart and load the existing save with Protected UI enabled. No other mod sources change. The four-mod bundle contains current Builders, Kopis/Astrid and Yaki Habitats unchanged.

This is a development build. XML/reference and mocked accounting/UI tests pass, but X4 is unavailable here. The new native remote hacking call, crew paths, save/load recovery and existing crystal firing/collection still require in-game verification. The report identifies other supplied-log errors without claiming they are fixed by this mod.
