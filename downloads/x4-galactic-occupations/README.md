# Galactic Occupations 0.3.3 — galaxy-wide crystal commerce

[Download Occupations](Galactic_Occupations_0.3.3_DEV.zip) · [Five-mod bundle](../x4-updates/X4_Crystal_Commerce_2026-11-07.zip) · [Crystal mechanics and tests](vardath_galactic_occupations/CRYSTAL_COMMERCE_0.3.3.md) · [Previous log fixes](vardath_galactic_occupations/LOG_REVIEW_0.3.2.md)

Crystal miners no longer follow the player. They simulate mining in actual off-screen ore/silicon fields across the permitted galaxy, backed by actual native resource depletion. Saved batches travel to a real dockable faction station for simulated inventory-trader sales, paying credits directly to you. Defaults: 24 items per five game minutes; normal Behaviour settings expose batch time/size. Real visible turret/drop harvesting remains and feeds the same sale stock. Existing player inventory is not swept.

Includes the log fixes for null sector caches, conflicting hacker order flags, real passenger room points, scanner prerequisites and credit units. The earlier log proves a 5,000,000 Cr luxury-tour payment and three 8,000 Cr patrol payments. It predates this mining implementation.

Fully exit X4, overwrite matching extensions, restart and load the existing save. Keep Protected UI and Inventory Collector. The bundle also includes Cargo Teleport 1.01 with a bounded native docking retry; Builders 1.75, Kopis/Astrid 1.15 and Yaki Habitats 1.23 remain unchanged. Green checks cover static/mocked tests and exact ZIP/source contents; new X4 engine integration remains unverified. Follow the included live test steps and keep a fresh debug log.
