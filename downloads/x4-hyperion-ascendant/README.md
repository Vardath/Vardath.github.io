# Hyperion Ascendant 1.0.0

[Download the ship and quest repair](Hyperion_Ascendant_1.0.0.zip) · [Full configuration and tests](vardath_hyperion_ascendant/README.md) · [All three updated mods](../x4-updates/X4_Hyperion_Tours_Update_2026-11-10.zip)

Separate player-owned Hyperion with 640,000 hull, reinforced shields, enhanced drive/handling, six dedicated main batteries and eight dedicated beam turrets. A Yaki-crewed replacement is supplied when no player-owned Ascendant remains. Existing ships are not overwritten.

Also replaces the original quest's stale per-sector gate lookup with native pathfinding through actual active gates, and can rebuild a stuck current sector search in an existing save. It preserves the original story and rewards; a disconnected map is not silently bypassed.

Requires Hyperion Pack and Cradle of Humanity. Exit X4, extract into its game directory, enable the extension and load the same save. Keep Protected UI and Inventory Collector. Use Galactic Occupations 0.4.8 for L/XL tour bookings and real passenger transporter transfers.

Source, native-reference, mocked failure and ZIP checks pass. Actual X4 ship/weapon/pathfinding behavior remains unverified without a game runtime. See the included acceptance steps.
