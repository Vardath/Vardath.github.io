# X4: Foundations — Vardath Living Factions & Builders

**Latest version: 1.3 — experimental X4 9.00**

**[Download v1.3 ready-to-install ZIP](./vardath_living_factions_builders_v1.3.zip)**

Extract the `vardath_living_factions_builders` directory to your X4 `extensions` folder. Replace v1.2 in place. **Cradle of Humanity DLC now required.**

**[Full features, installation and test instructions](./vardath_living_factions_builders/README.md)**

Version 1.3 adds a separate selectable New Game start: **Terran Shipwright — Yaki Company**, as a Terran woman wearing the white skirt/dress, aboard a player-owned Terran **Kyushu** builder with a veteran **Yaki** crew. The ship starts fully equipped with construction drones. This start is exclusive to a **new game** and requires **Cradle of Humanity DLC**.

Version 1.2 introduced a **200,000 Cr one-off faction hiring fee** plus **100,000 Cr per in-game hour constructing** or **25,000 Cr per hour awaiting construction**. A persistent, per-builder contract ledger records time already billed, debts and the employer. Wages are settled at hourly intervals and the final partial amount when the contract ends.

The v1.3 scripts are **structurally validated, but in-game payment and save/reload behaviour remain to be tested**.

Version 1.2 also fixed the active request broker's periodic reset and skips expensive faction station scans when no player builders are free. Version 1.1 ZIP is preserved for regression testing.
