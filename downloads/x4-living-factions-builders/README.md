# X4: Foundations — Vardath Living Factions & Builders

**Latest version: 1.2 — experimental X4 9.00**

**[Download v1.2 ready-to-install ZIP](./vardath_living_factions_builders_v1.2.zip)**

Extract the `vardath_living_factions_builders` directory to your X4 `extensions` folder. Replace v1.1 in place.

**[Full features, installation and test instructions](./vardath_living_factions_builders/README.md)**

Version 1.2 introduces a **200,000 Cr one-off faction hiring fee** plus **100,000 Cr per in-game hour constructing** or **25,000 Cr per hour awaiting construction**. A persistent, per-builder contract ledger records time already billed, debts and the employer. Wages are settled at hourly intervals and the final partial amount when the contract ends.

The v1.2 script is **structurally validated, but in-game payment and save/reload behaviour remain to be tested**.

Version 1.2 also fixes the active request broker's periodic reset and skips expensive faction station scans when no player builders are free. Version 1.1 ZIP is preserved for regression testing.
