# Vardath Cosmology — Book Manuscript

**Working title:** *Vardath Cosmology: The World That Opens*  
**Author:** Vardath / Stephen Michael Hawton  
**Status:** In development  
**Canonical research sources:** `vardath-cosmology.html` and the WordPress memory archive in this repository.

This directory is the working manuscript for the long-form Vardath Cosmology book.

## Why the manuscript is split into files

The research archive is large and continues to evolve. The book is therefore being written chapter by chapter rather than as one monolithic Markdown file. This gives us:

- durable Git history after every substantial writing batch;
- small, recoverable files if a session or connection fails;
- the ability to revise one chapter without risking the whole manuscript;
- a clean way to separate current cosmology, research history, comparative mythology and unresolved branches;
- an eventual path to combine the chapters into a print/PDF/EPUB manuscript.

## Manuscript rules

1. **The current model comes first.** Earlier versions are retained as development history, not silently presented as the current cosmology.
2. **Vardath's voice is primary.** The main manuscript explains the model from Vardath's point of view.
3. **Evidence classes remain visible.** Source tradition, established measurement, exact mathematics, modern analogy and Vardath interpretation are not treated as interchangeable.
4. **Failed branches stay in the story.** The literal polar map, simple three-beat clock, Moon-projector branch, outward-pressure gravity branch and other retired ideas are part of how the model became more disciplined.
5. **JANUS keeps its boundary.** Its audited mathematics can be explained exactly; it is not presented as having derived the physical cosmology.
6. **Mythology is compared by roles and sequences, not by declaring every god or symbol identical.**
7. **The book distinguishes the geometric core from more speculative extensions** such as upper-ocean support, waking-world biology, celestial incorporation and chronology.
8. **No source tradition is reduced to the Vardath reading.** The book explains the additional comparison rather than replacing the tradition's own historical meaning.

## Storage decision

The website repository is the best working home during drafting because it is versioned, durable and already contains the authoritative research sources. A local copy can be generated periodically as an additional backup, but GitHub should remain the canonical manuscript during active development.
