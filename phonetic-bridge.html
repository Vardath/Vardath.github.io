4. The 256 directed gates

Sixteen coarse states have 16² = 256 ordered state-pairs. This is a genuine mathematical state-transition space. PHOIBLE, however, is an inventory database rather than a speech corpus, so the page does not pretend that inventory ordering proves real transition frequencies.

5. Does the magic-square ordering beat chance?

This is the important control. We calculate a PHOIBLE-frequency-weighted feature centroid for each of the sixteen experimental cells. Then we follow the cells in the numerical order 1→2→…→16 induced by the classic Dürer 4×4 magic square and measure the total phonetic path length. Finally, we compare it with 5,000 random cell orderings.

Why this matters: a negative result is useful. If a proposed cell boundary repeatedly forces worse target matches, or if the magic-square path performs like random permutations, we can change or reject that part instead of protecting the theory from evidence.
