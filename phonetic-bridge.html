5. The 256 directed gates

Sixteen states yield 16² = 256 directed state-pairs. PHOIBLE establishes the segment states; WikiPron lexical pronunciations let us observe which transitions actually occur in word-level IPA trajectories.

6. Full WikiPron cross-language benchmark

The batch benchmark runs the same bridge over every indexed WikiPron dataset, then selects one canonical dataset per language for controlled cross-language analysis. Equal-size sampling prevents larger corpora from automatically appearing to have more gates.

Loading completed benchmark results…

Powers-of-3 transition profile

For a gate, the source and target magic-square cells define an exponent difference Δ, giving the ratio 3^Δ. These are the most widely recurring exponent deltas.

Gate prevalence across languages

Each percentage is the fraction of canonical languages in which that gate is stably observed. Hover a cell to see its gate and powers-of-three exponent delta.

Current full run: 543/543 WikiPron datasets completed, 348 canonical languages, 60,378 pairwise comparisons, and zero dataset failures. The strict 100% core is empty; the useful question is therefore the strength and stability of the high-prevalence backbone rather than whether every language uses exactly the same gates.

StatementStatus

The 16-cell compression is globally optimal.Not established
WikiPron lexical transitions equal continuous connected-speech articulation.No — acoustic validation remains separate

Why this matters: a negative result is useful. Cell boundaries, gate assumptions or mathematical overlays can be changed or rejected if the evidence says they should be.
