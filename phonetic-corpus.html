The 256 Gate Corpus Test

WikiPron supplies real IPA pronunciation sequences. PHOIBLE supplies the feature system used to place each IPA segment into the experimental 4×4 bridge. This page counts which of the 256 directed cell-to-cell gates actually occur inside words, how often they occur, and how similar those gate distributions are between languages.

6. What this tests

This is now a real transition test, but at the lexical-pronunciation level. It measures transitions inside dictionary pronunciations, not timing, coarticulation, sentence boundaries or spontaneous connected speech. A later acoustic stage can use recorded speech such as WikIPA/Lingua Libre to test whether the same coarse gates survive in actual audio.
