7. What this changes

A language does not need all 256 gates. Its observed subset is a gate footprint. The bridge only works as a useful universal layer if different languages show substantial reusable structure and if missing source gates can usually be rerouted through target-language gates at modest cost. Gate-count comparisons are sample-dependent; the strongest evidence comes from stable support under equal sampling, cross-family core gates, and low rerouting cost.
